# F.ETA.T — Fleet ETA Tracker

Веб-инструмент диспетчеров. Где машины (Mapon), сколько км и когда приедут (Google Routes API),
когда реально приедут с учётом тахографа (EU 561/2006), что мешает по пути (запреты, паромы).
Владелец — Владимир. Пользователи — он и диспетчеры. Интерфейс на русском.

Стек: Python 3 / Flask, gunicorn (`Procfile`: `gunicorn app:app`, 1 worker × 8 threads — общий кеш в памяти),
Cloud Run `fleet-eta-tracker`, europe-west1, проект `my-n8n-bot-496614`.
Вход — IAP по списку Google-аккаунтов. Общий Флот хранится в Firestore.
Фронтенд — ванильный JS без сборки (`static/`, `templates/index.html`). Карта Флота — панель справа (`static/map-panel.js`, механика в `app.js`). Боковые панели — общая ширина `--sidew` (500), закрытие кликом мимо — `SIDE_KEEP` в `app.js`.

## Правила работы (обязательно)

- **`git push` = деплой.** Cloud Build сразу выкатывает `main` на Cloud Run.
  Push только по явной команде **`//кодим`** или **`//деплой`** (одно и то же).
  До команды: готовим изменения локально, коммитим, докладываем и ждём.
- `//обс` — только обсуждение: без кода и деплоя.
- **Всё, о чём договорились в обсуждении, сразу идёт в НекстБилд** (`BACKLOG.md`, коммит без push) — не ждать отдельного `//запомни`.
  Что Владимир отложил («пусть висят») — в хотелки с найденными деталями, не в НекстБилд.
- **Номер версии — при `//кодим`, не раньше.** Договорённости из обсуждения пишутся в НекстБилд (`BACKLOG.md`) пунктами
  без номера; один `//кодим` забирает всё накопленное одним билдом. Если пункт лучше выкатить отдельно (рискованный,
  большой, трогает расчёт ETA / ✓ / деплой-критичное) — Claude перед сборкой говорит об этом и предлагает разделить
  («этот пункт отдельным билдом, потому что …»); решает Владимир. Просьба «добавь …» в обычном режиме — тоже кодим,
  но без отдельного номера и сдвига нумерации, пока нет `//кодим`.
- Версии `vX.YY`: X — ключевое изменение, YY — обычные билды. Ветка **3.x** — модульная структура (рефакторинг завершён в v3.05).
- Каждый билд:
  - поднимает `APP_VERSION` в `fetat/__init__.py`;
  - добавляет запись сверху в `CHANGELOG.md` (тест проверяет, что верхняя запись = `APP_VERSION`);
  - коммитится как `vX.YY: кратко что сделано`.
- Мата и шуток в коде нет. Комментарии и тексты UI — на русском.
- Новые зависимости в `requirements.txt` — только по согласованию.
- **Токены — как можно меньше (ПРИО 100):** точечные правки, без лишних проверок, перечитываний и длинных отчётов.

### Команды Владимира

- `//кодим` / `//деплой` / `//КиД` («кодим и деплоим») — собрать, проверить, закоммитить и **запушить** (= деплой). «//кодим 3,20» — номер билда.
- `//обс` — только обсуждение (договорённости всё равно записываются в НекстБилд).
- `//нб` / `//некстбилд` — показать НекстБилд и хотелки из `BACKLOG.md`.
- `//хотелки` — показать только хотелки (с приоритетами).
- `//напомни …` — записать мелочь из теста в раздел «Напоминания» `BACKLOG.md`; коммит без push.
- `//Как у вас?` — показать все висящие напоминания.
- `//глобал` — сводка: НекстБилд, Хотелки, Напоминания (роадмап-артефакт не трогает — для него `//роадмап`).
- `//роадмап` — обновить роадмап-артефакт «F.ETA.T» (https://claude.ai/artifact/69NT4HT59rDt9pnGWCoPTE, закреплён у Владимира)
  по `BACKLOG.md` и `CHANGELOG.md`: текущий / следующий билд, хотелки, напоминания, команды, последние билды.
  Источник правды — `BACKLOG.md` и `CHANGELOG.md`, артефакт — их витрина. Обновляется только по этой команде.
- `//прио N` (например `//прио4`) — поставить приоритет N хотелке, о которой сейчас речь; коммит без push.
- `//диз` — пометка «это про дизайн / вид»: обсуждаем внешний вид, механику не трогаем.
- `//нб_песочница` — режим: обсуждаем изменения для песочницы. Договорённости сразу пишутся в `BACKLOG.md`
  (к своей хотелке), но песочницу пока не трогаем — копим.
- `//песок` / `//песочница` — собрать накопленное: обновить песочницу (или сделать новую, если попросили) и дать ссылку.
  Правки — точечно в существующей странице, целиком заново — только новая версия (дорого по токенам).
- `//запомни …` — общая команда «запомнить»: сразу записать: план/хотелки → `BACKLOG.md`, правила работы и термины → сюда. Коммит без push (уйдёт со следующим `//кодим`).
- `//просто_спросить` — вопрос, не задача: ответить коротко, ничего не делать.
- `//переход` — подготовка к новому чату:
  1. сверить `BACKLOG.md`: все договорённости чата записаны, незакрытое помечено «не решено»;
  2. записать в `BACKLOG.md` короткую сводку перехода: текущая версия, что выкатили за чат, что проверить руками,
     на чём остановились;
  3. запушить коммиты, где только документация (`BACKLOG.md`, `CLAUDE.md`, `*.md`) — иначе новый чат их не увидит;
     если среди незапушенного есть код (начатый билд) — не пушить, предупредить и спросить `//кодим`;
  4. ответить одной строкой: можно переходить, какая версия на сервере, какие версии выкатили в этом чате (например,
     «v3.47–v3.50»), с чего начать в новом чате. В сводке перехода в `BACKLOG.md` версии чата тоже указываются;
  5. сохранить всю историю текущего чата в MD и конвертировать в PDF (pandoc + wkhtmltopdf); оба файла отдать Владимиру
     через SendUserFile; в репозиторий не коммитить;
  6. показать Владимиру пункты 1–5 результатом: что сделано, что не выполнено и почему (например, пуш без доступа на запись).
  Роадмап-артефакт `//переход` не трогает — для него отдельная команда `//роадмап`.
- «Блокнот ФЕТАТ — последние: N» — выгрузка из блокнота приложения: разобрать по пунктам, уточнить непонятное, предложить состав билда.

### Термины

- **Трип** — строка поездки во Флоте вместе с подстроками точек ②③…
- **Хозяин трипа** — диспетчер строки (`disp`), иначе создатель.
- **Справка** — вкладка [.] (в коде `notes`): история версий, состояние адресной базы и базы фрахтов, заметки, полезные ссылки.
  Не путать: **Песочница** — макет фичи отдельной страницей-артефактом на claude.ai (не в аппе, без деплоя):
  крутим, правим и только потом делаем билд; ссылки на песочницы — в хотелке в `BACKLOG.md`.
  **Блокнот** — записи-хотелки с категориями и статусами (панель справа и страница `/notebook`); **База** — Baza Parking, Riga.

### Начало нового чата

Прочитать только `BACKLOG.md` (версия на сервере — в сводке перехода). Память Claude по проекту не ведётся — всё живое здесь.
`ARCH.md` (модули, предметные правила, проверка перед `//кодим`) — читать только перед работой с кодом.

### Экономия токенов

- Длинный чат дорог: каждое сообщение перечитывает весь чат. **Один чат — одна тема или 1–2 билда**, потом `//переход` и новый чат.
- Большие файлы открывать только нужным куском; обсуждения и `//нб` — без чтения кода.
