# Песочница Флота (сборка макета)

Макет таблицы Флота для claude.ai: настоящие `static/*.js|css` + `index.html` из шаблона, `stub.js` подменяет `/api/*` данными из `snap.json`.
Порядок: `anon.py` (обезличить выгрузку Флота) → `compose.py` (8 L + 8 O + 5 без машины) → `snap.py` (расчёты ETA офлайн, настоящий Flask с подменёнными Mapon/Google) → `build.py <work> <dist>` → публикация `dist/` через Artifact (многофайловая).
Выгрузку Флота (реальные данные) в репозиторий не коммитить. Варианты вида — `variants.css/js`, двигалка колонок — `colorder.js`, переключатель сортировки — `sorttoggle.js`.
Пути внутри скриптов (рабочая папка) при необходимости поправить.
