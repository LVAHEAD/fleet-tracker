# Песочница Флота — всё по ней

**Что это.** Макет таблицы Флота 1-в-1 на claude.ai (не в аппе, без деплоя): настоящие `static/*.js|css` + `index.html` из шаблона, поверх — `stub.js`, который подменяет `/api/*` данными из `snap.json`. Крутим вид и поведение здесь, потом делаем билд.
**Ссылка (опубликована):** https://claude.ai/artifact/GSJevvQWyxg8FriTi7XA9L (закрыт, владелец — Владимир). Обновляется повторной публикацией в тот же артефакт.

## Что значит «пересобрать»
Сама песочница остаётся в артефакте и работает. Пересобрать нужно, когда мы хотим **обновить её под новый код аппы** (после билда поменялись `static/*`, `templates/index.html`) или **добавить новые варианты**. В новом чате рабочая папка с данными пропадает (это временная папка сессии), поэтому скрипты хранятся здесь, а данные берутся заново. Для мелкой правки вида пересборка не нужна: достаточно поправить `variants.css` / `variants.js` в самой песочнице (дёшево по токенам).

## Состав
- `anon.py` — обезличивает выгрузку `/api/fleet` (машины, прицепы, клиенты, e-mail, телефоны, референсы). `python3 -I anon.py <in.json> <out.json>`
- `compose.py` — набирает таблицу: 8 строк L + 8 строк O + 5 без машины (`fleet_anon_full.json` → `fleet_anon.json`).
- `snap.py` — офлайн-снимок ответов аппы (`snap.json`): настоящий движок аппы, подменённые Mapon/Google (расстояние = гаверсинус ×1,25, 72 км/ч), время заморожено на `now` выгрузки. `python3 snap.py <рабочая папка>`
- `build.py <work> <dist>` — копирует `static/*`, собирает `index.html` (url_for убран, скрипт Google Maps убран, ключей нет), кладёт `snap.json`, `fleet.json`, `ferries/`, `postcode-maps/`.
- `stub.js` — подмена `fetch('/api/*')` из `snap.json`, заглушка Google Maps; **подключается первым**.
- `variants.css` / `variants.js` — варианты вида и переключатели внизу страницы. **С 28.10 пусто (в css только бледно-зелёный фон страницы): «Фикс-время точки» выкачено в v3.229, макет убран; `stub.js` отдаёт `/api/mapon-object-at` (вымышленные зоны и группы Mapon, у каждого третьего адреса зоны нет) — для строки «Mapon» в карточке адреса.** **С 25.10 (v3.211) оба файла пусты (комментарий): макет мобильного вида Паромов убран, цепочка перецепа выкачена.** До этого — **25.10 (v3.207–v3.209):** раскладка 700 px, фильтры по странам, блок «Заказ паромов» и мобильный вид Паромов выкачены в аппе; `variants.js` пока хранит макет «📱 Мобильный вид» — при пересборке под v3.209+ убрать, оставив файл пустым. **С 22.10 (v3.187) пусты:** шапка B + C выкачена в аппе (склеенный T / +1 / +2, ▸ с рамкой, ▾ без рамок, одна линия, «Дата» / «Клиент» / «Референс»), песочница собрана на коде v3.187 и выглядит как прод. Новые варианты и их переключатели — сюда.

## Как собрать заново (новый чат)
1. Попросить у Владимира свежую выгрузку Флота (`/api/fleet`, JSON); реальные данные **в репозиторий не коммитить**.
2. Рабочая папка в scratchpad: `anon.py` → `compose.py` → `snap.py` → `python3 -I build.py <work> <dist>`.
3. Страница-файл без doctype/html/head/body (оболочку добавляет публикация). Публикация: Artifact с `url` на артефакт выше, `file_path` = `dist/index.html`, `files` = остальные файлы папки `dist/`.
4. Проверка локально Playwright-ом (Chromium уже есть): открыть `dist/` через `http.server`, посмотреть скриншот.

## Что в макете настоящее, а что заглушка
Настоящее: таблица, фильтры, сортировка, панели-выезжалки (Запреты, Ссылки, Адреса, Карта, Блокнот, ⏱) — код аппы. Заглушки: ⏱, From→To, Локатор, Блокнот, ⛽ (содержимое пустое/смоделированное); карты серые; правки не сохраняются; клиенты и машины выдуманные.

## Принятые решения (21.10) → смотри `BACKLOG.md`, НекстБилд

## Нюансы, на которых уже спотыкались
- ключи расчётов в `snap.json` должны совпадать с `JSON.stringify([unit,target,extra])` (без пробелов, `ensure_ascii=False`);
- после перестановки столбцов правила на `td:first-child` и `td:nth-child(3)` надо привязывать к `data-ci` (см. `variants.css`);
- в `build.py` проверка на ключ Google: ищем `maps/api/js` и `key=`, а не слово `googleapis`;
- в `anon.py` / `build.py` вшиты реальные e-mail диспетчеров для замены на `dispatcher1@` / `dispatcher2@example.com`.

## После выкатки билда (договорённость 21.10)
Песочница должна соответствовать текущему состоянию аппы. Версии песочниц отдельными артефактами не копим: у артефакта есть история публикаций, старое состояние можно вернуть из неё. После `//кодим`, который выкатил вид, по `//песок`: 1) пересобрать из нового `static/`; 2) из `variants.css` / `variants.js` убрать варианты, ставшие настоящими (иначе наложатся дважды) и их переключатели; 3) опубликовать в тот же артефакт. Новый артефакт — только если Владимир просит сохранить старую песочницу рядом.

## Пересборка без свежей выгрузки (21.10, v3.184)
Обезличенные `snap.json` и `fleet.json` берём из опубликованного артефакта (`Artifact read` с `paths`) — просить выгрузку не нужно. `index_raw.html` рендерим из шаблона через Flask test client (`FLEET_STORE=memory`, заголовок `X-Goog-Authenticated-User-Email`), `gets["/api/changelog"]` в `snap.json` заменяем свежим ответом `/api/changelog`. `build.py` не переименовывает диспетчеров повторно (пропускает `@example.com`) — иначе VL терял роль и кнопки T/+1/+2 и метка не показывались. Локальная проверка: оболочка с `<meta charset="utf-8">` (публикация её добавляет сама), Playwright. При публикации удалённые файлы передаём как `null` в `files`.
